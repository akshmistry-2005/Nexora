1. **Defect:** Autogenerated Alembic migration failed initially because `Table("role_permissions")` used ORM `mapped_column` instead of Core `Column`.

   **Fix:** Adjusted campaign flight duration to `75..120` days in `scripts/seed_database.py` and reseeded.
3. **Defect:** `scripts.reset_database` import failed in pytest due to `sys.path` not containing the project root.  
   **Fix:** Added root directory path resolution in `test_m03_t11_database_reset_test`.
